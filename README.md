# RustServerManager

Десктопное приложение (WPF, .NET 8) для управления выделенным сервером **Rust**.

## Возможности

- 🚀 Запуск / остановка / обновление сервера `RustDedicated.exe` через SteamCMD
- 📊 Мониторинг ресурсов (CPU, RAM, uptime) и количества игроков
- 🔌 Подключение к RCON через WebSocket (логи, команды, список игроков)
- 👥 Кик и бан игроков из интерфейса
- 💾 Создание резервных копий сервера и Oxide (ZIP)
- 🧹 Вайп карты и чертежей
- 📝 Редактирование `server.cfg` (имя, maxplayers, worldsize, seed, rcon.password)
- 🧩 Поиск, установка и управление плагинами uMod/Oxide
- ⚙️ Редактирование конфигов плагинов
- ❄️ Зимняя тема с анимированным снегом

## Требования

- Windows x64
- [.NET 8 SDK](https://dotnet.microsoft.com/download) для сборки
- Rust-сервер (для RCON-функций)

## Сборка

```bash
dotnet build RustServerManager.sln -c Release
```

Исполняемый файл появится в `RustServerManager/bin/Release/net8.0-windows/`.

## Использование

1. Запустите приложение.
2. Укажите папку, в которой лежит `RustDedicated.exe`.
3. Запустите сервер или подключитесь к нему через RCON.
4. Управляйте плагинами, игроками и конфигурацией через вкладки.
